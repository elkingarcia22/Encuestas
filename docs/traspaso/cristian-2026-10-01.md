## 1. Arrancar en un computador vacío

El computador nuevo no tiene nada: ni programas, ni llaves, ni sesiones. Este documento vive en el repo, así que **la
primera vez se lee desde la web de Bitbucket** (con tu sesión en el navegador):
https://bitbucket.org/techubits/playground-ux/src/cristian/docs/traspaso/cristian-2026-10-01.md

### 1.1 Programas básicos
1. Las herramientas de desarrollo de Apple, que traen git. Se abre una ventana: acepta.
   ```bash

   ```
2. Claude Code. También puedes bajar la app de escritorio de Claude y usar su pestaña Code.

   Al abrirlo por primera vez, inicia sesión con la cuenta de la empresa.

Node, Homebrew y AWS CLI no se instalan a mano: los instala el script del proyecto (paso 1.4).

### 1.2 Llave para Bitbucket (una sola vez)
Aquí se usaba una llave SSH propia para Bitbucket. En el computador nuevo hay que crear otra:
1. Crear la llave (pulsa Enter en todo):
   ```bash
   ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_bitbucket -C "cristian-pc-nuevo"
   ```
2. Copiarla:
   ```bash
   pbcopy < ~/.ssh/id_ed25519_bitbucket.pub
   ```
3. Pegarla en Bitbucket: tu foto › **Personal settings** › **SSH keys** › **Add key**.
4. Decirle al computador que use esa llave con Bitbucket:
   ```bash
   printf 'Host bitbucket.org\n  HostName bitbucket.org\n  User git\n  IdentityFile ~/.ssh/id_ed25519_bitbucket\n  IdentitiesOnly yes\n' >> ~/.ssh/config
   ```
5. Probar. Tiene que responder con tu usuario; la primera vez pregunta si confías en el servidor: escribe `yes`.
   ```bash
   ssh -T git@bitbucket.org
   ```

## 3. Planes de formación: qué se hizo y por qué

Carpeta: `src/modules/admin/aprendizaje/planes-de-formacion/`. Rutas: `/admin/aprendizaje/planes-de-formacion/planes`
(y `…/grupos`).

**Principio que manda (Cristian):** «mantener la misma estructura y patrón de acciones [del producto real] pero con mejor
UI». Se calca el flujo del admin real de UBITS y se mejora la interfaz, sin darle la vuelta.

### Decisiones de Cristian, ya aplicadas
- **Lista de planes**: tocar la fila (o el nombre) abre el plan en un panel lateral. Sin menú ⋯ ni enlace «Ver
  progreso» (lo llamó «terrible»). `?vacio` en la URL muestra el estado de primera vez.
- **Ver plan** (`components/panel-plan.tsx`), en un panel lateral de 32rem:
  - arriba, el avance;
  - pestañas «Contenidos» (tarjetas con banner) y «Personas» (en lista).
  - «Sí o sí tarjetas, y las personas como listas.»
- **Editar** = el **mismo panel**, que cambia de modo. Lleva Cancelar y Guardar (sin autoguardado) y pregunta «¿Descartar
  los cambios?». Nada de dos paneles seguidos: la animación entre paneles la llamó «horrible».
- **Crear** (`components/formulario-plan.tsx`, `FormularioPlan`) = **una sola página, sin pasos**:
  - el nombre en una fila y las fechas en otra;
  - debajo, asignaciones y contenidos;
  - a la derecha, el panel «Vista previa»;
  - barra fija abajo con Cancelar · Guardar.
- **Estructura de Crear** = la misma de David en Crear contenido y Diagnóstico: cada bloque en un marco gris (`Frame`)
  con el título afuera, y «Vista previa» con el nombre, los datos y «Faltan N datos» (`components/resumen-plan.tsx`).
  Antes de inventar un panel de resumen en Aprendizaje, mirar esas pantallas en staging.
- **Agregar asignación** (`components/agregar-asignacion.tsx`): panel ancho con pasos según el tipo:
  - empresa: Tipo → Contenido;
  - colaborador o grupo: Tipo → Participantes → Contenido;
  - archivo CSV: Tipo → Cargar archivo.
- **Competencias**:
  - salen del catálogo real compartido (`src/shared/bd`: 35 competencias con imagen y 156 habilidades);
  - tienen un «Enfoque por habilidades» opcional; si no se marca nada, se estudian todas.
- **Tablas** = `TablaDatos` del design system, en español: los textos fijos de la librería se traducen solos
  (`design-system/data-grid/textos-libreria.ts`) y los ajustes van en `tabla-datos.css`.
- **Campo de fecha** (`CampoFecha` / `RangoDeFechas`) de 40 px, con selector de mes y año.

- **Tablas** todas iguales a la del DS: caja gris, título, conteo, buscador a la derecha, filtros y orden por columna,
  paginación en español.
- **Pestañas**: la maestra es la subrayada, fuera de la tabla. El switch solo en casos especiales.

  - título y descripción fijos, acciones a la derecha;

- **Una sola pieza por cosa**:
  - panel = `DrawerShell`, nunca Sheet directo;
