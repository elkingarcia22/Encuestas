# Memoria de Claude (computador anterior de Cristian, hasta el 1-oct-2026)

Copia tal cual de las notas que Claude guardaba en `~/.claude/projects/<repo>/memory/`. Cada archivo es un hecho, una
decisión o una trampa; `MEMORY.md` es el índice.

**En el computador nuevo**, para que Claude las vuelva a tener como memoria propia, pídele:

> Copia los archivos de `docs/traspaso/memoria-claude/` (menos este LEEME.md) a tu carpeta de memoria de este proyecto y
> confírmame cuántos quedaron.

Son el contexto de una persona en un momento dado: si una nota choca con lo que dice hoy el código, `CLAUDE.md` o
`AGENTS.md`, gana lo de hoy. El resumen ordenado está en `../cristian-2026-10-01.md`.
