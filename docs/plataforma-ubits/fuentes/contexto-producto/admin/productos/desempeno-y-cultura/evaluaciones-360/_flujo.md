# Flujo — Evaluaciones 360°

## Objetivo

Que HR diseñe y active evaluaciones 360° con tipo, competencias, evaluados y resultados, y gestione el listado (filtrar, finalizar, eliminar).

## Actores

- Administrador de recursos humanos

## Pasos de creación (hub)

1. Confirmar nombre + fechas → desbloquea **Tipo**.
2. Completar Tipo (pesos de tipos activos = 100%).
3. Competencias (cada tipo activo ≥ 1 enunciado).
4. Evaluados y Resultados.
5. Activar solo con las 4 secciones completas.

## HUs

`HU-DES-001`, `HU-DES-002`.
