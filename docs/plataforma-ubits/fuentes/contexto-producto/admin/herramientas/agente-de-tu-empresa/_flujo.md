# Flujo — Agente de tu empresa

Un agente por empresa, alimentado por colecciones. No es el chat genérico Agente IA ni Modo estudio IA.

Única HU: [HU-TRA-001](HU-agente-de-tu-empresa.md).

## Admin

1. Herramientas → Agente de tu empresa
2. Home: cara del agente + listado (lista / cards, árbol ilimitado). El App Header muestra solo actual y padre (si hay).
3. Crear colección en la home (nombre + visibilidad + documentos; default Público). Adentro: crear carpeta (hereda visibilidad). Drawer sm sobre el listado. Editar agente también es un drawer sm (imagen, nombre, tono). Generar con IA abre una capa del mismo drawer (mismo flujo que generar portada: prompt, 50 tokens, regenerar o guardar).
4. Dentro de una colección o carpeta: subir documentos y/o crear carpetas
5. Probar agente (IA panel) solo desde la home, y solo si hay ≥1 colección con ≥1 documento (sin «Ver como»)

## Colaborador

1. Rail Agentes
2. Si tiene ≥1 colección visible → primera card Agente de tu empresa
3. Chat + historial → clic en el número de cita → panel del documento
